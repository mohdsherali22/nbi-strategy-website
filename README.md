# NBI Strategy (Next Business Intelligence) — AI Services Website

A fast, dependency-free marketing website for **NBI Strategy — Next Business
Intelligence**, an AI & technology services company for SMB owners and founders. Three
practices: **AI & Automation** (workflow automation, chatbots, digital
employees on Hermes / OpenClaw, voice AI, advanced/self-hosted systems),
**Software & Platforms** (ERP, SaaS, website building) and **Growth &
Marketing** (SEO & AEO, content creation, cold outreach & lead generation).
The core funnel is the free **AI Automation Readiness Score** on
`assessment.html`, which scores visitors 0–100 and routes them to one of four
fixed-scope offers (Starter Automation Package, AI Workflow Sprint, AI Audit +
90-Day Roadmap, Growth Engine). No prices appear anywhere — everything is
"fixed scope, quoted after your Readiness Score."

## Pages

| File | Purpose |
|---|---|
| `index.html` | Homepage — funnel hero, stats, agent network, 4 offer cards, 3 practice-group cards, about, integrations, before/after proof, CTA, newsletter |
| `assessment.html` | AI Automation Readiness Score — 9-step quiz, score dial, offer routing, report capture |
| `services.html` | All 14 services under 3 practice groups (AI & Automation · Software & Platforms · Growth & Marketing) |
| `about.html` | Studio story, values, stats, disciplines |
| `insights.html` | Six AI-focused articles + newsletter |
| `contact.html` | Consultation form with qualification fields (role, size, urgency, authority, budget band), office details, FAQ |

Also generated: `sitemap.xml`, `robots.txt`. All pages carry OG/Twitter meta
and Organization JSON-LD; the contact page adds FAQPage JSON-LD.

## Stack

- **Pure HTML / CSS / JavaScript** — no build step, no frameworks, no dependencies
- Google Fonts (Marcellus + Manrope)
- All lead forms — contact, newsletter, assessment quiz and assessment report —
  POST JSON to the existing n8n webhook configured in `assets/js/main.js`
  (`LEAD_ENDPOINT`). Assessment payloads carry `form: "assessment"` /
  `"assessment-report"` plus every answer, the score and the routed segment.
- Pages are generated by `tools/generate_website.py` in the repo root —
  edit that file and re-run it rather than editing the HTML by hand.

## Deploy

Upload the folder contents to any static host (Hostinger, Netlify, Vercel,
GitHub Pages). No server-side code required.
