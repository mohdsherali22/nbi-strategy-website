# NBI Strategy (Next Business Intelligence) — AI Services Website

A fast, dependency-free marketing website for **NBI Strategy — Next Business
Intelligence**, an AI & technology services studio building workflow
automations, AI chatbots & knowledge assistants, AI agents & digital employees
(Hermes / OpenClaw), voice AI, AI business tools, AI apps & SaaS MVPs, and
advanced agentic / self-hosted systems.

## Pages

| File | Purpose |
|---|---|
| `index.html` | Homepage — hero, stats, 7 service cards, about, integrations marquee, example engagements, CTA, newsletter |
| `services.html` | Detailed breakdown of all nine service lines (6 core + 3 advanced) |
| `about.html` | Studio story, values, stats, disciplines |
| `insights.html` | Six AI-focused articles + newsletter |
| `contact.html` | Consultation request form, office details, FAQ |

## Stack

- **Pure HTML / CSS / JavaScript** — no build step, no frameworks, no dependencies
- Google Fonts (Marcellus + Manrope)
- Lead forms POST to the existing n8n webhook configured in `assets/js/main.js`
  (`LEAD_ENDPOINT`)

## Deploy

Upload the folder contents to any static host (Hostinger, Netlify, Vercel,
GitHub Pages). No server-side code required.
